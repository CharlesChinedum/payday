# Payday web app

Next.js app with the employer and worker pages, the gasless relayer (`/api/relay`), account onboarding (`/api/onboard`) and the NEAR Intents 1Click quote proxy (`/api/quote`).

See the [project README](../README.md#3-use-the-web-app) for setup, the relayer allowlist and a step-by-step walkthrough.
